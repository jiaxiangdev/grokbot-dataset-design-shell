# Grokbot catalog design shell

This repository is a design shell for redesigning the Grokbot catalog page.

The posts dataset is not in this repo. `catalog.js` holds three labeled sample records so the page can open and the list, filters, and detail view have something to draw. Those samples were written for the shell. They are not records from the dataset, and they do not include collected posts.

## Open it

Open `index.html` in a browser. No install, build, or local server is required. The page loads `site.css`, `catalog.js`, and `app.js` from this folder.

## What is here

- `index.html`, `site.css`, and `app.js` — the catalog page
- `fonts/ip-inter-var-latin.woff2` — Inter, used by the page
- `identity/instructplus-lockup-horizontal-light.svg` — Instruct+ lockup
- `identity/icon-64-IP-001.png` — favicon
- Role marks in `identity/` and `identity/marks/`
- Staff cards `identity/cards/IP-001.png` through `identity/cards/IP-300.png`

The staff cards are brand art. They are not the posts dataset.
